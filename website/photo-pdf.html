HOW IT WORKS

사진에서 PDF까지, 네 단계면 됩니다.

  1. 홈에서 사진 → PDF를 누르고 필요한 사진을 선택합니다.
  2. 페이지 순서와 방향을 확인하고 필요한 사진만 남깁니다.
  3. 제목과 화질을 선택해 새 PDF로 저장합니다.
  4. 완성된 파일을 열어 확인한 뒤 필요한 앱으로 공유합니다.

작은 글씨가 있는 서류는 고화질로 저장한 뒤 결과 파일을 확대해 확인하세요.
