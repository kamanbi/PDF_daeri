HOW IT WORKS

받은 PDF도 휴대폰에서 정리합니다.

  1. PDF 열기에서 정리할 문서를 엽니다.
  2. 편집 화면에서 불필요한 페이지를 삭제하거나 방향을 회전합니다.
  3. 사진 또는 PDF 페이지를 필요한 페이지의 앞·뒤에 추가합니다.
  4. 순서를 확인하고 새 파일로 저장합니다.

이 기능은 기존 PDF 본문의 글자를 직접 수정하는 방식이 아니라, 페이지를 정리하는 기능입니다.
