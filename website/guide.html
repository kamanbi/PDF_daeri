HOW TO 01

사진 여러 장을 PDF 하나로 만들기

안내문이나 제출할 서류를 이미 사진으로 찍었다면 다시 스캔할 필요가 없습니다.

  1. 홈에서 사진 → PDF를 누르고 필요한 사진을 선택합니다.
  2. 편집 화면에서 사진 순서를 확인하고, 방향이 틀린 사진은 회전합니다. 불필요한 부분은 자릅니다.
  3. 저장을 누르고 제목과 화질을 확인합니다.
  4. 완성된 PDF를 열어 누락된 페이지가 없는지 확인한 뒤 공유합니다.

작은 글씨가 있는 서류는 고화질을 선택하고 결과를 확대해 읽어보세요. 흐린 원본 사진은 화질 옵션만으로 선명해지지 않습니다.

HOW TO 02

PDF 페이지 삭제·회전·추가하기

받은 PDF에서 필요 없는 페이지를 지우거나, 빠진 서류 사진을 페이지 사이에 넣을 수 있습니다.

  1. PDF 열기에서 문서를 열고 편집 화면으로 이동합니다.
  2. 페이지를 선택해 회전하거나 삭제합니다. 필요한 페이지만 별도 문서로 저장할 수도 있습니다.
  3. 페이지 추가에서 사진 또는 스캔을 선택하고, 선택 페이지의 앞·뒤 또는 마지막에 삽입합니다.
  4. 페이지 순서를 확인하고 새 파일로 저장합니다.

PDF 대리의 편집은 페이지 정리 기능입니다. 기존 PDF 본문 글자를 워드처럼 직접 수정하는 기능은 제공하지 않습니다.

HOW TO 03

PDF 용량 줄이고 공유하기

메일이나 메신저에 첨부하기 전에 압축 기능으로 용량을 줄일 수 있습니다. 문서에 따라 압축 효과는 다릅니다.

  1. 문서의 작업 메뉴에서 압축을 선택합니다.
  2. 작은 글씨는 고화질, 일반 문서는 기본, 용량을 우선하면 최소 옵션의 설명을 확인합니다.
  3. 압축한 결과의 크기와 글자 선명도를 확인합니다.
  4. 공유를 눌러 휴대폰에 설치된 메신저·메일 등으로 전달합니다.

이미 최적화된 PDF는 크게 줄지 않을 수 있습니다. 특정 감소율이나 첨부 용량을 보장하지 않습니다. 공유 대상은 휴대폰에 설치된 앱에 따라 달라집니다.

필요한 기능을 부담 없이.
